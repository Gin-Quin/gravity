This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

Use Bun 1.4.4 or newer. Install dependencies from the repository root, then run
the example scripts from this directory:

```sh
bun run dev
bun check
bun run build
```

The build script checks types before starting the framework build.
